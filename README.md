# Моделювання руху вантажу на пружині (Варіант 3)

Програма моделює вертикальні коливання вантажу на пружині під дією сили тяжіння та сили пружності (Закон Гука).

## Стек
* **Мова:** C++17
* **Графіка:** SFML
* **Збирання:** CMake + vcpkg
* **IDE:** Visual Studio 2022

## Керування
* `UP` / `DOWN` — маса вантажу
* `LEFT` / `RIGHT` — жорсткість пружини
* `SPACE` — пауза / запуск
* `R` — перезапуск

## Запуск
1. Відкрити папку проєкту у Visual Studio (`File -> Open -> Folder`).
2. Зачекати налаштування CMake та vcpkg.
3. Зібрати та запустити `Spring_Lab`.
